# ZET-WAVE-Optimization-Membrane-Based-Wastewater-Treatment-for-STIG-Plants
he project focuses on the ZET (Zentrum für Energietechnik) Condensate Treatment Plant at TU Dresden. The plant operates a steam-injected gas turbine (STIG) process that recovers boiler feedwater from flue gas condensation. providing a 3.3x safety margin and eliminating all WAVE design warning
